# EMC Academy Website (HTML Practice)

A beginner HTML project built while following a web development tutorial
by the EMC YouTube channel: https://www.youtube.com/@ErrorMakesClever

## Pages
- index.html: home page with an embedded video, lists and a table
- register.html: course registration form

## What I practiced
- HTML structure, headings, paragraphs and lists
- Tables
- Embedding a YouTube video with iframe
- Forms (text, number, radio, email, dropdown, file upload)
- Linking multiple pages together

## Note
The registration form is not connected to a backend yet.
This is a practice project and only uses HTML.
